## 🏠 Airbnb Sentiment Analysis: Trustpilot Web Scraping & NLP
Este proyecto se enfoca en la extracción masiva de datos y el análisis de sentimientos de las reseñas de Airbnb publicadas en Trustpilot. El objetivo principal es transformar datos no estructurados en información valiosa mediante técnicas de Procesamiento de Lenguaje Natural (NLP) y Machine Learning.

## 🚀 Descripción del Proyecto
El flujo de trabajo abarca desde la recolección de datos hasta la implementación de un modelo predictivo:

-Extracción de Datos (Web Scraping): Obtención de grandes volúmenes de comentarios de Airbnb directamente desde Trustpilot.

-Procesamiento de Lenguaje Natural (NLP): Limpieza, tokenización y normalización de los textos para su análisis.

-Análisis de Sentimientos: Clasificación automatizada de las reseñas para entender la percepción de los usuarios.

-Modelo de IA: Entrenamiento de un modelo de clasificación capaz de predecir si un nuevo comentario es Positivo, Negativo o Neutro.

## 🛠️ Tecnologías Utilizadas
Scraping: BeautifulSoup

Análisis de Datos: Pandas, NumPy

NLP & ML: NLTK, Scikit-learn

Lenguaje: Python
